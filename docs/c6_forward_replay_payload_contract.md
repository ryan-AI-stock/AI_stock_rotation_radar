# C6 Forward Replay Payload Contract

Publisher input path: `data/c6_current_snapshot.json`.

The current C6 ranking snapshot is versioned research data only. A complete
forward account payload must be generated by the frozen C6 execution engine;
the dashboard publisher must not infer it from rankings or adjusted prices.

## Required scope

- `model_version`: immutable frozen C6 version.
- `snapshot_as_of`: Taiwan trading date covered by the materialized replay.
- Start state: `2026-08-05`, cash `7000000`, three slots, no inherited
  positions.
- Every signal day must provide Top1 through Top3 or an explicit official
  market/session status. A missing source day is not an empty candidate day.
- Every execution, daily held mark, corporate-action unit change and withdrawal
  event needs an official raw price or explicit `official_no_trade` evidence.

    }

The publisher already adds immutable snapshot/event keys. `slots` must be the
actual end-of-day state at `snapshot_as_of`; it cannot be reconstructed from
rank rows. `ledger_rows` must contain the official price lineage in the replay
manifest referenced by `source_manifest_hash`.

## Current blocker

The available `C6_SCORE_0_actions.csv` gives signal/action diagnostics only.
It lacks whole-share quantities, 7m cash balances, official raw daily held
marks, costs, event/unit treatment, and the 2026-08-05 initial state. It is
therefore insufficient for a C6 simulated-account ledger.
