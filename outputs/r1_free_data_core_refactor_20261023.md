# R1 免費資料核心重構稽核

日期：2026-10-23  
狀態：`challenger / report-only`

## 模型目的

R1以免費、可持續取得且具PIT性的資料，維護AI瓶頸題材與正式候選池，衡量長期持有優先順序，並只在現有持股轉弱且替代股具明顯優勢時提供人工換倉參考。R1不自動交易，法人EPS與目標價只作信心覆核，不阻斷免費資料核心。

## 本輪找到並修正的問題

1. 舊換倉程式只要候選總分略高就可能配對換出持股，與長抱、低週轉目的衝突。
   - 修正：持股的價格籌碼安全或題材催化必須降至40分以下；候選兩項都至少50分；核心總分至少高10分。
   - 任一實際持股缺完整核心分數時，停止推導換倉，不把缺資料當成弱勢。
2. 免費價格籌碼風險沿用舊四項權重，缺少EPS歷史時會隱含重配剩餘權重。
   - 修正：明定免費三項權重為價格過熱安全50%、法人籌碼33.33%、融資結構16.67%，三項缺一即NA。
3. 官方自身估值資料缺失時會退回法人Forward PE，與免費核心獨立原則衝突。
   - 修正：禁止回退；官方自身歷史估值缺失就保留NA。
4. `r1_v05_policy.json`仍保留舊七構面權重，和實際五構面引擎不同。
   - 修正：政策檔同步為五構面25%／25%／15%／15%／20%，法人目標價獨立為0%核心權重的信心層。
5. 新增政策一致性測試，防止程式常數與政策檔再次漂移。

## 尚需驗證

- 10分差、40分弱勢與50分健康門檻是具經濟意義的保守第一版，尚未宣稱歷史最佳；需用forward累積及小型敏感度檢查驗證穩定區間，不能用單期最高績效調參。
- 催化分數多數落在中性50分，需檢查事件覆蓋率與衰減是否使構面辨識力不足。
- 月營收年增率目前採52檔截面百分位；需檢查產業季節性及基期效應，避免單月低基期主導營收兌現分。
- 4W／12W EPS歷史只作信心層，不是免費核心阻擋條件。
