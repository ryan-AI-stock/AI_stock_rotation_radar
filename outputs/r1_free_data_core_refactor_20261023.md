# R1 免費資料核心重構稽核

日期：2026-10-23  
狀態：`challenger / report-only`

## 模型目的

R1以免費、可持續取得且具PIT性的資料，維護AI瓶頸題材與正式候選池，衡量長期持有優先順序，並只在現有持股轉弱且替代股具明顯優勢時提供人工換倉參考。R1不自動交易，法人EPS與目標價只作信心覆核，不阻斷免費資料核心。

## 本輪找到並修正的問題

1. 舊換倉程式只要候選總分略高就可能配對換出持股，與長抱、低週轉目的衝突。
   - 修正：持股的價格籌碼安全或題材催化必須降至40分以下；候選兩項都至少50分；核心總分至少高10分。
   - 任一實際持股缺完整核心分數時，停止推導換倉，不把缺資料當成弱勢。
2. 免費價格籌碼風險沿用舊四項權重，缺少EPS歷史時會隱含重配剩餘權重。
   - 修正：明定免費三項權重為價格過熱安全50%、法人籌碼33.33%、融資結構16.67%，三項缺一即NA。
3. 官方自身估值資料缺失時會退回法人Forward PE，與免費核心獨立原則衝突。
   - 修正：禁止回退；官方自身歷史估值缺失就保留NA。
4. `r1_v05_policy.json`仍保留舊七構面權重，和實際五構面引擎不同。
   - 修正：政策檔同步為五構面25%／25%／15%／15%／20%，法人目標價獨立為0%核心權重的信心層。
5. 新增政策一致性測試，防止程式常數與政策檔再次漂移。

## 尚需驗證

- 10分差、40分弱勢與50分健康門檻是具經濟意義的保守第一版，尚未宣稱歷史最佳；需用forward累積及小型敏感度檢查驗證穩定區間，不能用單期最高績效調參。
- 催化分數多數落在中性50分，需檢查事件覆蓋率與衰減是否使構面辨識力不足。
- 月營收年增率目前採52檔截面百分位；需檢查產業季節性及基期效應，避免單月低基期主導營收兌現分。
- 4W／12W EPS歷史只作信心層，不是免費核心阻擋條件。

## 第二輪修正

1. 月營收兌現由「最新單月年增率」改為「最近三個已公布月份年增率平均」。
   - 三個單月截面排名的Spearman相關係數為0.87至0.92，整體尚算穩定，但個股最新單月與三月平均排名最多可差24名。
   - 改用三月平均符合R1一至六個月持有視角，並降低單月基期與認列時點造成的跳動。
2. 催化證據檔104筆全部為正向事件，沒有任何負向事件，不能視為完整的題材強弱樣本。
   - 在負向事件取得流程尚未驗證前，免費核心的催化構面全池固定中性50分。
   - 原始正向催化分仍保留為診斷欄位，但不再因「好消息較容易被建檔」而墊高核心排名。
3. 以2026-10-22資料重算：52／52檔仍完整可評；Top5未改變；平均名次變動2.0名，最大16名。

後續真正需要補強的是負向事件的系統化免費來源與PIT規則，而不是再調催化權重。

## 第三輪修正

1. 新增官方負面證據層，完全由已下載的MOPS月營收與財報衍生，不依賴新聞情緒或人工主觀標籤。
   - 月營收：最近三月平均年增率與最新月年增率同為負數。
   - 營運：財報營收年增率與EPS年增率同為負數。
   - 現金與利潤：毛利率、營業利益率同時惡化，且營業現金流為負。
2. 2026-10-22共辨識11項事實、涉及8／52檔；`future_data_violation_count=0`。
3. 這些事實不任意換算扣分，也不改五構面總分；只用於換倉檢視的風險守門：
   - 有官方惡化旗標的持股可以進入人工優先檢視。
   - 有官方惡化旗標的替代候選不得被列為健康換入標的。
4. 財報負面證據的`available_at`採本次官方財務快照日期，是偏晚、較保守的PIT口徑，不把財報期末日誤當成市場當時已知日。
5. 每週流程已改為先完成月營收、官方財報、財務品質及負面證據，再生成週資料與R1排名；每日流程沿用最近一次已驗證的負面證據檔。

驗證：R1測試246項通過；免費核心仍為52／52可評。
